# 英语阅读器

一个 Chrome 扩展。装上之后接管浏览器自带的 PDF 阅读器,读英文 PDF 时划词即查、顺手收录生词。

词典是离线的,查单词不联网;整句翻译走在线接口。

![界面](screenshot.png)

## 功能

- **划词查词** —— 选中单词立刻出音标和中文释义,内置 5.9 万条离线词库,自动归并词形(`Statistical` 能命中 `statistical`,`went` 能命中 `go`)
- **划句翻译** —— 选中整句或短语自动出译文,可以连原文带译文一起收进生词本
- **生词本** —— 单词和句子都能存,自动记录来自哪个 PDF、第几页
- **导出 CSV** —— UTF-8 带 BOM,双击用 Excel 打开不乱码,也能直接喂给 Anki

## 环境要求

- Chrome 151 或更高版本(用的是 Chrome 官方新加的 `chrome.mimeHandler` 接口)
- Edge 不支持,`mimeHandler` 是 Chrome 独有的

## 安装

1. 下载本仓库(右上角 Code → Download ZIP,或者 `git clone`)
2. 打开 Chrome,地址栏输入 `chrome://extensions` 回车
3. 打开右上角的「开发者模式」开关
4. 点左上角「加载已解压的扩展程序」,选中本文件夹
5. 之后双击任意 PDF、或在网页上点 PDF 链接,都会进这个阅读器

> **别移动或重命名这个文件夹。** 开发者模式下,扩展的身份是由文件夹路径决定的。路径一变,身份就变,扩展读不到之前存的生词了。要挪地方的话,先导出 CSV 备份。

## 使用

| 操作 | 结果 |
|---|---|
| 划选一个单词 | 弹出音标 + 中文释义,点「加入生词本」收录 |
| 划选一句话或短语 | 自动出中文译文,同样可以收录 |
| 点右上角「生词本」 | 打开侧栏,翻看和删除已收录的内容 |
| 点「导出 CSV」 | 把全部生词存成表格文件 |
| 「适应宽度」 | 让 PDF 铺满窗口;两边 `−` `+` 手动缩放 |

生词本是**所有 PDF 共用的一份**,不按文件分开。每条都记着来自哪个文件、第几页,导出的 CSV 里也分成两列。

## 数据

生词存在 `chrome.storage.local` 里:

- 关浏览器、重启电脑、清缓存、Chrome 自动更新 —— 都**不会丢**
- 卸载扩展会一起删掉,所以重要的话定期导出一份 CSV
- 数据只在本机,不上传不同步(Chrome 跨设备同步配额只有 100 KB,装不下大量生词)

## 实现说明

浏览器自带的 PDF 查看器处在受保护环境里,扩展无法往里注入脚本 —— 所以这个扩展不是「在原生查看器上叠加功能」,而是**接管 PDF 的显示**:Chrome 把 PDF 交给扩展的页面渲染,地址栏仍然保留原始的 PDF 路径。

渲染用 PDF.js。点击「适应宽度」时按阅读区宽度计算缩放,画布分辨率取屏幕像素密度(`devicePixelRatio`),所以在高分屏上依然锐利。

## 文件说明

| 文件 | 说明 |
|---|---|
| `manifest.json` | 扩展清单,声明 `mime_types_handler` |
| `viewer.html` / `viewer.css` / `viewer.js` | 阅读器界面与逻辑 |
| `pdf.min.js` / `pdf.worker.min.js` | PDF.js 3.11.174 |
| `dict.js` | 离线英汉词库,59111 条 |

`dict.js` 由 [ECDICT](https://github.com/skywind3000/ECDICT) 的完整词库(77 万词条)裁剪而来:保留有词频记录的词条,以及带柯林斯星级、牛津 3000、各类考试标签的词条,释义截断到 110 字符。想扩容的话,改一下筛选条件重新生成即可。
